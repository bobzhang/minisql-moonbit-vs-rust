# M8 coverage: reading SQLite database files

Every test has a `sqlite` phase that builds the file with real SQLite and an
`engine` phase that only reads it. A few tests switch between SQLite and the
engine more than once. The mapping below follows the bullets in SPEC §4 (M8)
and the topics the test plan asked for.

## File header, page sizes, UTF-8

| Topic | Files |
|---|---|
| Page size 512, 1024, 2048, 4096, 8192, 16384, 32768 | `page_size_<N>.sql` (one file per size) |
| Page size 65536 (stored as 1 at header offset 16) | `page_size_65536.sql` |
| Page size changed after the data is loaded (VACUUM 1024 to 8192) | `vacuum_and_page_size_change.sql` |
| UTF-8 text: accents, CJK, emoji, combining marks, non-ASCII identifiers | `non_ascii_text.sql`, `collate_nocase_columns.sql` |

## Schema table and objects

| Topic | Files |
|---|---|
| Schema b-tree on page 1, including page 1 as an interior page and schema records that overflow | `schema_many_tables.sql` |
| Tables, indexes and views listed in `sqlite_schema` | `empty_table.sql`, `autoindex_unique_primary_key.sql`, `views_in_schema.sql`, `alter_rename_drop_by_sqlite.sql`, `sqlite_changes_between_reads.sql` |
| `sqlite_autoindex_*` from UNIQUE and non-integer PRIMARY KEY (single and multi-column, TEXT/REAL keys) | `autoindex_unique_primary_key.sql`, `overflow_index_keys.sql`, `rowid_alias_integer_primary_key.sql` |
| Index CREATE text with DESC, expressions, partial WHERE, COLLATE, UNIQUE | `index_expression_partial_desc.sql`, `collate_nocase_columns.sql` |
| Views: column lists, joins, aggregates, compound, CTE, window, views of views | `views_in_schema.sql`, `schema_many_tables.sql`, `sqlite_changes_between_reads.sql` |
| Varied CREATE syntax: quoted identifiers (`"…"`, `[…]`, backticks), keywords as names, comments and newlines, multi-word and parameterized types, named constraints, REFERENCES/FOREIGN KEY, CHECK, DEFAULT forms, COLLATE, ON CONFLICT | `schema_varied_syntax.sql` |
| CREATE TABLE … AS SELECT (schema text generated by SQLite) | `schema_varied_syntax.sql` |
| `sqlite_sequence` from AUTOINCREMENT | `autoincrement_sqlite_sequence.sql`, `rowid_alias_integer_primary_key.sql` |
| Declared-type affinity parsed from the stored schema | `affinity_from_file_schema.sql`, `schema_varied_syntax.sql`, `real_stored_as_integer.sql` |
| Empty database holding only one empty table | `empty_table.sql` |

## B-trees

| Topic | Files |
|---|---|
| Single-leaf root pages, tiny tables | `btree_single_leaf.sql`, `empty_table.sql` |
| Deep table and index b-trees (several interior levels, page_size=512, 60k rows) | `btree_deep_512.sql`, `page_size_512.sql`, `page_size_1024.sql` |
| Multi-level trees at every page size | `page_size_<N>.sql` |
| Index b-trees: lookups, ranges, ordering, composite keys | `btree_deep_512.sql`, `page_size_<N>.sql`, `mixed_type_index.sql`, `autoindex_unique_primary_key.sql` |
| Mixed storage classes in one index (NULL < numbers < text < blob; 2 = 2.0) | `mixed_type_index.sql` |
| Emptied trees (DELETE row by row and the DELETE-all fast path) | `delete_all_rows.sql` |

## Records and serial types

| Topic | Files |
|---|---|
| Serial types 0, 8, 9 and integer widths 1/2/3/4/6/8 at both boundaries | `serial_types_integers.sql` |
| REAL (7), empty/short/long TEXT and BLOB, multi-byte serial-type varints | `serial_types_text_blob_real.sql` |
| Whole-number REALs that SQLite stores with an integer serial type in REAL columns | `real_stored_as_integer.sql` |
| Record header longer than 127 bytes (2-byte header-size varint) | `wide_table_many_columns.sql` |
| Record header that does not fit locally (continues on an overflow page) | `wide_table_many_columns.sql` |
| Columns added by ALTER TABLE ADD COLUMN missing from older records (use the DEFAULT) | `alter_add_column_defaults.sql`, `sqlite_changes_between_reads.sql` |

## Overflow pages

| Topic | Files |
|---|---|
| Table-leaf payloads at exactly X-1, X, X+1, X+2 and at the `M + (P-M) % (U-4)` limit | `page_size_<N>.sql` |
| Index payloads at exactly the index limit and in the index remainder case | `page_size_<N>.sql` |
| Chains of many overflow pages (up to about 12 at 1 KiB, 5 at 64 KiB) | `overflow_text_chains.sql`, `page_size_<N>.sql`, `overflow_columns_after_big_value.sql` |
| Columns stored after a large value (read from the overflow area) | `overflow_columns_after_big_value.sql` |
| Long index keys (plain index, UNIQUE autoindex, composite) | `overflow_index_keys.sql`, `page_size_<N>.sql` |
| Overflow chains rewritten by UPDATE (freed and reallocated pages) | `overflow_text_chains.sql` |

## Rowids

| Topic | Files |
|---|---|
| INTEGER PRIMARY KEY alias (NULL in the record); table-level PRIMARY KEY(id); `INT`/`BIGINT PRIMARY KEY` and `INTEGER PRIMARY KEY DESC`, which are not aliases | `rowid_alias_integer_primary_key.sql` |
| Rowid gaps, negative rowids, 9-byte varints, min/max int64, huge sparse keys in interior cells | `rowid_extremes.sql` |

## Free space

| Topic | Files |
|---|---|
| Freelist trunk and leaf pages after DROP TABLE and mass DELETE (auto_vacuum=NONE) | `free_pages_after_delete.sql`, `delete_all_rows.sql` |
| Freeblocks, fragmented bytes, cell pointers out of address order | `freeblocks_fragmented_pages.sql` |
| Files compacted by VACUUM | `vacuum_and_page_size_change.sql` |

## ALTER TABLE done by SQLite

| Topic | Files |
|---|---|
| ADD COLUMN with DEFAULT (integer, real, text, blob, NULL, `(expr)`, NOT NULL, COLLATE) | `alter_add_column_defaults.sql` |
| RENAME TO, RENAME COLUMN (index and view text rewritten), DROP COLUMN | `alter_rename_drop_by_sqlite.sql`, `sqlite_changes_between_reads.sql` |

## M1 to M7 query features on file tables

| Topic | Files |
|---|---|
| Joins (inner, LEFT, RIGHT, FULL, NATURAL, USING, self, multi-way, CROSS) | `query_joins_on_file.sql` |
| Aggregates, GROUP BY/HAVING, DISTINCT/FILTER, group_concat ORDER BY, date/time, printf, string functions | `query_aggregates_dates_on_file.sql` |
| Recursive and plain CTEs, window functions, frames, named windows | `query_windows_ctes_on_file.sql` |
| Subqueries (scalar, IN, EXISTS, correlated, FROM), UNION/INTERSECT/EXCEPT, DISTINCT/LIMIT/OFFSET, VALUES | `query_subqueries_compound_on_file.sql` |
| Collations from column declarations | `collate_nocase_columns.sql` |
| Errors on file databases (missing table/column, writing to a view) | `empty_table.sql`, `views_in_schema.sql`, `alter_rename_drop_by_sqlite.sql`, `schema_many_tables.sql` |

## Several processes

| Topic | Files |
|---|---|
| SQLite changes the file between engine reads (data, indexes, ALTER, DROP, views) | `sqlite_changes_between_reads.sql`, `vacuum_and_page_size_change.sql`, `empty_table.sql` |
